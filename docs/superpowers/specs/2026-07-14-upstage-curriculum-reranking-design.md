# Upstage 성취기준 재정렬 설계

## 목표

교사가 입력한 챗봇 이름, 과목, 학교급, 학년, 수업 주제, 학습 목표를 바탕으로 기존 내부 검색이 찾은 2022 개정 교육과정 성취기준 후보를 Upstage가 재정렬한다. Upstage가 응답하지 않거나 응답을 신뢰할 수 없으면 현재 내부 검색 순서를 그대로 사용한다.

## 모델 선택

실제 교육과정 후보를 사용한 비교에서 `solar-pro2`가 24/24 사례의 정답 후보를 1위로 선택했고, 반복 측정 중앙 응답시간은 1.49초였다. 같은 조건에서 `solar-pro3`는 전체 24회 중 23회 정답 1위, 반복 중앙값 2.06초였고 `solar-mini`는 첫 8회 중 6회 정답 1위였다. 따라서 기본 재정렬 모델은 `solar-pro2`로 한다.

## 데이터 흐름

1. 기존 `CurriculumIndex.search()`가 사용자 입력으로 후보를 검색한다.
2. 학교급, 학년, 과목 필터를 기존 방식 그대로 적용한다.
3. 상위 후보의 ID, 과목, 영역, 학교급, 학년군, 성취기준 원문을 Upstage에 전달한다.
4. Upstage는 후보 ID만 관련성 순서대로 반환한다.
5. 서버는 실제 후보에 존재하는 ID만 받아들이고 중복을 제거한다.
6. 모델이 생략한 후보는 기존 내부 순서로 뒤에 붙인다.
7. 최종 상위 8개를 현재 API 응답 형식으로 반환한다.

## 폴백 계약

다음 조건에서는 Upstage 결과를 사용하지 않고 기존 내부 후보 순서를 그대로 반환한다.

- `UPSTAGE_API_KEY`가 없거나 비어 있음
- 네트워크 오류 또는 제한 시간을 초과함
- Upstage가 2xx가 아닌 상태를 반환함
- JSON 응답 구조가 올바르지 않음
- 반환된 후보 ID 중 유효한 ID가 하나도 없음
- 후보가 0개 또는 1개라 재정렬할 필요가 없음

부분적으로 유효한 응답은 유효한 후보 ID만 반영하고, 나머지는 내부 순서로 보충한다. 따라서 후보 밖 성취기준은 사용자에게 노출되지 않는다.

## 구성

- `UPSTAGE_API_URL`: 기본값 `https://api.upstage.ai/v1`
- `UPSTAGE_API_KEY`: 서버 전용 인증 키
- `UPSTAGE_MODEL`: 기본값 `solar-pro2`
- `UPSTAGE_TIMEOUT_MS`: 기본값 `3000`

비밀 키는 클라이언트 번들에 포함하지 않는다.

## 검증

- 재정렬 성공, 후보 밖 ID 제거, API 오류, 잘못된 JSON, 시간 초과, 키 누락 폴백을 자동 테스트한다.
- 전체 테스트와 TypeScript 빌드를 통과시킨다.
- 로컬 서버에서 실제 Upstage 호출과 강제 폴백을 HTTP로 확인한다.
- 브라우저에서 교사 챗봇 생성 화면을 조작해 추천 순서가 표시되는지 확인한다.
